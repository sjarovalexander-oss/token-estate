# TokenEstate (демо)

Демо на платформа за токенизация на имоти: примерна сграда, 200 токена по 5 000 €.
Всички данни са измислени. Състоянието се пази в браузъра (localStorage), без бекенд.

- `/` – проектът: 3D сграда, продажба на живо, калкулатор, график, защити
- `/market` – вторичен пазар
- `/profile` – профил на инвеститора
- `/admin` – админ панел (етапи, траншове, KYC, новини)

Next.js 14 + three.js. `npm install && npm run dev`
