# TokenEstate (демо)

Демо на платформа за токенизация на реални активи. Шест секции, по един примерен проект във всяка:
ново строителство, соларна енергия, имоти под наем, ремонт и препродажба, хотели, земеделска земя.
Всички данни са измислени. Състоянието се пази в браузъра (localStorage), без бекенд.

- `/` – каталог по секции
- `/sector/[slug]` – страница на секция
- `/project/[id]` – проект: кадри по етапи, продажба на живо, калкулатор, график
- `/market` – вторичен пазар (по проект)
- `/profile` – профил на инвеститора
- `/admin` – админ панел (етапи, траншове, KYC, новини)
